# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within WhimsicalArt, please send an email to the project maintainers. All security vulnerabilities will be promptly addressed.

**Please do NOT report security vulnerabilities through public GitHub issues.**

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Fix release**: Depends on severity

## Security Best Practices

When contributing to this project:

- Never commit secrets, API keys, or credentials
- Use HTTPS for all network calls
- Validate all user inputs
- Follow Android security best practices
- Don't log sensitive information

## Dependencies

We regularly audit our dependencies for known vulnerabilities. If you discover a vulnerability in a dependency, please report it following the process above.
