Face landmarking model
======================

File: face_landmarker.task
Source: MediaPipe Face Landmarker (478-landmark face mesh), task bundle
URL: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task

Hair segmentation model
=======================

File: hair_segmenter.tflite
Source: MediaPipe Hair segmentation model (hair / background segmentation)
URL: https://storage.googleapis.com/mediapipe-models/image_segmenter/hair_segmenter/float32/latest/hair_segmenter.tflite

Skin segmentation model
=======================

File: skin_segmenter.tflite
Source: MediaPipe SelfieMulticlass segmentation model (background / hair /
body-skin / face-skin / clothes / others); only the face-skin channel is used
URL: https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_multiclass_256x256/float32/latest/selfie_multiclass_256x256.tflite

All models are executed fully on-device via the MediaPipe Tasks (LiteRT)
libraries; no image data leaves the device.
